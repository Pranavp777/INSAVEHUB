Complete Instagram Video Specifications Guide: Aspect Ratios, 1080p Bitrates & Codecs

Whether you are a digital content creator, social media archivist, or media production studio, understanding Instagram's video ingestion engine is critical for delivering crisp, artifact-free 1080p playback.

1. Instagram Aspect Ratio & Resolution Matrix

Instagram enforces strict aspect ratio limits. Uploading a video that deviates from these ratios triggers automatic crop or letterboxing algorithms that degrade visual presentation.

Format Type Aspect Ratio Optimal Resolution Max Frame Rate Target Bitrate
Reels (Vertical) 9:16 1080 x 1920 px 60 fps (30 recommended) 3,500 – 5,500 kbps

2. Video Codec & Container Architecture

Instagram's ingestion servers parse uploaded MP4 containers through an automated transcoding cluster. To avoid destructive secondary re-compression, your source file should align as closely as possible to Meta’s native pipeline:

  • Container: ISO Base Media File Format (MP4 / QuickTime). Ensure the moov atom is placed at the front of the file (FastStart flag enabled) so mobile browsers can begin playback before the entire file downloads.
  • Video Codec: Advanced Video Coding (AVC / H.264). We recommend High Profile @ Level 4.1 or Main Profile. While Instagram internally tests AV1 and VP9 for select accounts, H.264 remains the universal standard across all mobile devices.
  • Chroma Subsampling: YUV 4:2:0. Videos exported in 4:2:2 or 4:4:4 color formats will suffer gamma shifts and oversaturation upon ingestion.
  • Color Space: Rec. 709 (sRGB transfer curve). Do NOT upload in HDR (Apple Log, DCI-P3, HLG, or Rec. 2020) without tonemapping to SDR Rec. 709; otherwise, non-HDR displays will show washed-out, milky gray tones.
  • Keyframe Interval (GOP Size): Closed GOP with keyframes every 1 to 2 seconds (e.g., GOP=60 frames at 30fps). This enables seamless variable-rate scrubbing in Instagram's mobile player.

3. Audio Codec & Bitrate Requirements

Poor audio encoding frequently results in clipping, tinny treble, or out-of-sync playback. Use these exact specifications:

  • Audio Codec: AAC-LC (Advanced Audio Coding - Low Complexity).
  • Sample Rate: 44.1 kHz or 48.0 kHz (standard broadcast rate).
  • Bitrate: 128 kbps to 256 kbps, Constant Bitrate (CBR) stereo.
  • Loudness Normalization: Aim for -14 LUFS integrated loudness with true peaks below -1.0 dB TP. Instagram applies automatic gain attenuation to loud audio, creating muddy compression pump artifacts.

4. Production-Ready FFmpeg Export Script

For video editors and developers seeking byte-perfect rendering, execute the following command in terminal or command prompt: 

ffmpeg -i input_master.mov \
  -vf "scale=1080:1920:force_original_aspect_ratio=decrease,pad=1080:1920:(ow-iw)/2:(oh-ih)/2,format=yuv420p" \
  -c:v libx264 -preset slow -profile:v high -level 4.1 \
  -b:v 4500k -maxrate 5500k -bufsize 9000k \
  -g 60 -keyint_min 60 -sc_threshold 0 \
  -c:a aac -b:a 192k -ar 48000 \
  -movflags +faststart \
  output_instagram_reel.mp4
